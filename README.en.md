# Multimodal Multi-Task Shaft Fault Learning (Code Snapshot)

This source snapshot contains models, data-loading interfaces, and training/evaluation entrypoints for compound shaft-fault recognition. The project's current maintenance record identifies FreqToken Transformer v4 as the mainline; TCN is a historical baseline, not the latest model.

## Release scope

Raw waveforms, data splits, label tables, model weights, experiment outputs, and internal research reports are excluded. Prepare data you are authorized to use and verify local configuration.

## Reproduction

Install `requirements.txt`, inspect the training/evaluation arguments, and adapt them to your data layout. Report the dataset version, speed split, and metric granularity with any results.
